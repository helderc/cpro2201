## 💻 Getting the Code

You can download the repository as a ZIP file or clone it using Git.

## 🐍 Python Version

Unless otherwise specified, examples are intended to run with a recent version of Python 3.

Check your Python installation with:

```bash
python --version
```

or:

```bash
python3 --version
```

## ▶️ Running an Example

Navigate to the appropriate folder and run the Python file:

```bash
python filename.py
```

For example:

```bash
python 01-example.py
```

Some examples may require additional packages. If a particular example has additional requirements, they will be documented in the corresponding folder or file.
